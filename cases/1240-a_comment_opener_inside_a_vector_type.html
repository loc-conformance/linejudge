1240-a_comment_opener_inside_a_vector_type

C3 writes a vector of unknown length as int[<*>], and its compiler reads [< as one token, so the <* sitting inside that type never opens the documentation comment that <* opens everywhere else. The file carries a real one above the macro as well, so the numbers cannot come out right by ignoring <* altogether
